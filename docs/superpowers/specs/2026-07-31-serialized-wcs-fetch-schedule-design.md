# WCS 拉取与计算串行调度设计

## 目标

接口模式仍以“上一次拉取开始时间”为 200 秒周期起点，但计算期间不得再次拉取、
更新库存表或启动另一轮计算。

## 调度规则

每轮执行顺序固定为：

1. 记录本轮拉取开始时间 `T`。
2. 拉取一次库存。
3. 库存有变化时，在同一调度流程中完成本轮计算。
4. 计算结束后比较当前时间与 `T + download_interval`：
   - 尚未到期：只等待剩余时间；
   - 已经到期：不再等待，立即开始下一轮拉取。

因此，若计算耗时 100 秒且间隔为 200 秒，计算结束后再等待约 100 秒；若计算耗时
250 秒，则计算结束后立即拉取。

## 范围

- `接口持续运行`采用上述串行调度。
- `运行至成功`采用相同的周期锚点规则。
- `接口单次运行`保持不变。
- 库存无变化时不计算，并等待到本轮周期结束。
- 拉取、计算或停止的既有异常处理保持不变。

## 实现边界

移除持续模式中并行的拉取线程和装箱线程，改为单一循环依次执行拉取与计算。
使用单调时钟计算剩余等待时间，避免系统时间调整影响周期。停止事件继续负责中断
等待和结束服务。

## 验证

自动化测试只覆盖本需求明确的两个时间行为：

- 计算在间隔内完成时，仅等待剩余时长。
- 计算超过间隔时，不等待并立即进入下一次拉取。
