# 「平顶不缺角」约束说明（正常订单）

> 甲方 2026-07 需求。面向工程人员：讲清楚约束口径、判定规则、实现位置、开关与实测影响。

## 1. 需求口径（已与甲方确认）

- **正常订单** = 箱子全是「规则箱」的订单。
- 正常订单的**达标盘**（整盘指数 ≥ 目标 192）必须：
  1. **顶面平**：所有暴露顶面同一高度，**零容差**；
  2. **四周不缺角**：判定看**整圈周边**——垛型每个高度层的外圈四壁都被箱面
     铺满，箱间摆放缝（≤ 6mm）不算缺口；缺口藏在垛内部允许。
- **尾盘**（订单最后装不满的未达标盘）**整盘豁免**。
- 仅对 **MH423C** 托盘生效（MH110 不要求）。
- 本轮指数仍按「≥192 达标」执行，不设上限。
- Excel 文件与 WCS 接口两种计算方式**同时生效**（共用同一装箱核心）。

## 2. 「规则箱 / 正常订单」判定

与 UI 看板（`ui/dashboard_state.py` 规则/不规则计数）同口径：规格存在
**逐轴整数倍伙伴**——订单内另有一种规格，长/宽/高按对应轴（不旋转）之比均为
整数。订单内**每种规格都有伙伴**才算正常订单。

- 668 规则数据集：8 种规格两两成对 → 整单判**正常**。
- 5000 混杂数据集：三个订单都含孤立规格（如 430×280×430）→ 判**不正常**，
  平顶约束不适用（零回归）。
- 与 UI 的唯一刻意差异：**单规格订单判为正常**（UI 把孤立规格计为不规则是
  看板统计口径；单规格订单是最容易平顶满铺的场景，业务上属于"全规则箱"）。

实现：`src/utils/normal_order.py`。判定按（托盘类型, 原始销售订单号）整单
进行，给每个箱子打内部标记 `_normal_order`（输出前剥离），标记随箱子流经
主装箱、全部救援与重排路径。

## 3. 实现结构

| 层 | 位置 | 职责 |
|---|---|---|
| 判定与打标 | `src/utils/normal_order.py`、`src/main/workflow.py` | 按原始订单整单判定，箱级打标（拆分/改名前） |
| 形状校验 | `src/geometry/flat_top.py` | 顶面零容差等高 + 每层外圈四壁铺满（缝 ≤ 6mm） |
| 统一门禁 | `src/geometry/constraint_validator.py` | 达标 ∧ 全箱带标 ∧ 类型在范围 ∧ 非守恒兜底盘 → 校验形状；救援链/择优棘轮/最终门禁自动获得拦截能力 |
| GCP 生成侧 | `src/packing/global_column_packer.py` | ①柱类型键并入柱高（盘内柱等高→顶面平）；②pattern 限同高柱；③落地：网格结果过外圈预检，不过改 **CP-SAT 完美平铺**（全部柱装入 W×Hy=面积和 的候选外接矩形，无内洞、四壁天然不缺）；④铺砌失败 pattern 拉黑后 **ILP 重解**（≤3 轮），残余库存换组合再凑达标盘 |
| beam 出盘兜底 | `src/main/pallet_packer.py`、GCP 残料段 | 达标但形状不合格的盘出盘前**拆顶**：先试拆出暴露的合规子堆保住达标盘，拆不出则降级尾盘（豁免），拆下的箱退回剩余池 |

## 4. 开关与配置（`config/packing_config.yaml` → `constraints` 段）

```yaml
flat_top_full_perimeter_enabled: true   # 总开关（false = 完全恢复历史行为）
flat_top_pallet_types: [MH423C]         # 适用托盘类型
flat_top_seam_tolerance_mm: 6.0         # 周边铺满允许的箱间缝（顶面等高恒零容差）
```

## 5. 实测影响（2026-07-31，本机）

| 数据集 | 约束关（基线） | 约束开 | 说明 |
|---|---|---|---|
| 668 规则单订单 | 11 盘 11 达标，**其中 3 盘缺角/台阶** | 12 盘 **10 达标全部平顶不缺角** + 2 尾盘（130/62 指数） | 达标 -1；尾盘是 350×265/530×350 混高零头，三种底面铺不成完整矩形 |
| 5000 混杂三订单 | 179 盘 138 达标 | 179 盘 138 达标（一致） | 非正常订单不适用，零回归 |
| 全量 pytest | 227 通过 | 227 通过（含新增 24 个形状/分类单测） | — |

- 668 端到端耗时约 90s → 165s（CP-SAT 完美平铺 + ILP 重解的代价）。
- 旧输出里「达标但缺角」的典型盘（每层最后一排仅 1–2 箱、两角贯通全高缺失）
  在约束开启后不再产出。

## 6. 已知边界

- 尾盘不止一个时（如 668 出 2 个尾盘）均按尾盘豁免；甲方口径的"尾箱"按
  「未达标盘整盘豁免」实现。
- 完美平铺比「整圈周边不缺」更强（内部也无洞）；若未来允许"外圈完整、
  内部留洞"的达标盘，可在 CP-SAT 落地上放松，换回部分达标率。
- 大规模正常订单（柱类型 > 14 走贪心路径）不做生成侧收紧，靠门禁拦截 +
  拆顶降级兜底，达标率可能偏低；当前现场订单规模未触发。
- 箱型尺寸需为 5mm 倍数（CP-SAT ÷5 无损缩放前提），本项目箱型均满足。
