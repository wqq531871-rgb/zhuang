# 规则箱与不规则箱数量设计

## 目标

在主界面右侧“操作建议”上方新增“规则箱子数目”和“不规则箱子数目”两个指标卡。装箱结果加载后自动统计当前结果内全部托盘的箱子，结果清空时恢复为 `--`。

## 判定口径

- 优先使用箱子的 `original_length`、`original_width`、`original_height`，其次使用 `raw_length`、`raw_width`、`raw_height`，最后才使用 `length`、`width`、`height`，避免算法添加的间隙影响整数倍判断。
- 先按唯一的 `(长, 宽, 高)` 规格归组。
- 两个不同规格在长、宽、高三个对应方向上，较大值除以较小值均接近正整数时，这两个规格都属于规则规格。
- 一个规格只要能与至少另一个规格满足上述关系，该规格下的全部箱子计入规则箱。
- 没有匹配规格、尺寸缺失或尺寸非正数的箱子计入不规则箱。
- 浮点整数倍判断采用 `1e-6` 容差。

## 界面

沿用现有 `MetricCard` 样式，在右侧核心指标网格末尾增加一整行：

- 左侧：规则箱子数目
- 右侧：不规则箱子数目

该行位于“重心偏移”之后、“操作建议”之前，与用户截图标注位置一致。

## 数据流

结果 JSON 加载为 `self.pallets` 后，纯统计函数遍历所有托盘的 `packed_items`，返回 `(规则箱数, 不规则箱数)`。`populate_after_load()` 将结果写入两张指标卡；`clear_current_views()` 将两张卡恢复为等待状态。

## 测试

- 成对整数倍规格均计入规则箱，孤立规格计入不规则箱。
- 使用原始尺寸时，不受有效尺寸中 `+2 mm` 间隙影响。
- 尺寸缺失或非正数时计入不规则箱。
- 多托盘数据合并统计。
- UI 冒烟测试确认两张卡存在并能显示加载后的统计值。
