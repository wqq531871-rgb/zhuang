========================================
完整方案接收端 — 给对方的运行说明
========================================

一、你需要收到的文件（整个文件夹即可）
----------------------------------------
把下面这个目录原样拷贝到对方电脑（可打成 zip）：

  peer_internal_receiver/
  ├── run_receiver.py
  ├── requirements.txt
  ├── config/receiver_config.yaml
  └── 给对方的运行说明.txt   （本文件）


二、重要概念（先看这个，避免填错 IP）
----------------------------------------
1) host: "0.0.0.0"
   - 这是「在本机监听所有网卡」，不是 IP 地址，不要改成对方/我方的 192.168.x.x
   - 对方电脑上必须保持 0.0.0.0，局域网才能连进来

2) advertise_base_url: http://192.168.0.202:8094
   - 这里才写「对方电脑自己的局域网 IPv4」
   - 用来告诉我方：请 POST 到这个地址
   - 对方换 IP 时只改这一行，并通知我方同步改 packing_config.yaml

3) 我方下传完整 URL =
     advertise_base_url + internal_path
   例: http://192.168.0.202:8094/adaptor/api/wcs/internal


三、对方配置哪里改
----------------------------------------
文件: config/receiver_config.yaml

  TODO(监听地址) host: "0.0.0.0"          ← 一般不动
  TODO(端口)     port: 8094               ← 若改端口，通知我方
  TODO(本机对外根地址) advertise_base_url ← 填对方自己的 IPv4
  TODO(保存目录) save_dir                 ← 默认 D:/research_code/xiafa
  TODO(接口 path) internal_path           ← 与我方一致，勿乱改


四、安装与启动
----------------------------------------
  cd peer_internal_receiver
  pip install -r requirements.txt
  python run_receiver.py

保持窗口开着。Swagger:
  http://127.0.0.1:8094/swagger/index.html

防火墙放行入站端口 8094。
提前创建目录: D:\research_code\xiafa


五、我方要对齐的配置（装箱侧）
----------------------------------------
文件: packing-system/config/packing_config.yaml

  # TODO(完整方案下传-对方根地址)
  internal_base_url: http://192.168.0.202:8094
  internal_path: /adaptor/api/wcs/internal

注意: 不要填 api_base_url(192.168.0.191:8092)，那是 WCS，不是本接收端。
