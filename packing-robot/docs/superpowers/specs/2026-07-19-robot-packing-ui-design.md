# 机器人装箱可视化系统设计

## 目标

构建一个基于 PyQt5 的桌面程序，读取装箱算法 JSON，筛选指定指标状态的托盘，按机器人装箱顺序显示每个箱子的抓取和放置数据，并用三维等轴投影视图模拟吸盘从传送带抓取箱子后放置到托盘的过程。

## 已确认需求

- 左侧提供 JSON 文件导入。
- 左侧提供指标状态下拉框，默认选择 `SUCCESS`，并支持 `ALL`、`FAILED`、`UNKNOWN`。
- 左侧提供传送带箱子姿态下拉框，可手动设置 `0°` 或 `90°`。
- 吸盘规格固定为 600 × 800 mm。
- 托盘平面以左上角为局部坐标原点，界面俯视投影中 X 向右、Y 向下，Z 向上。
- 输出抓取 Z、吸盘角点、箱子角点、放置 X/Y/Z 和吸盘旋转角度。
- 按 `robot_packing_sequence` 播放；缺少该字段时退回 `original_packing_sequence`，再退回数组顺序。

## 数据解释

- 箱子放置基准坐标直接取 `position.x/y/z`。
- 箱子顶面 Z 为 `position.z + raw_height`；缺少 `raw_height` 时使用 `height`。
- 吸盘放置中心由 `suction_rect_*` 的矩形中心计算。
- 吸盘目标姿态：`cup_600x_800y` 为 0°，`cup_800x_600y` 为 90°。
- 旋转命令为目标吸盘姿态与用户设置的传送带箱子姿态之差，归一化为 0° 或 90°。
- 抓取接触 Z 为可配置的“传送带平面 Z + 箱子高度”；界面同时明确这是局部接触面数据，不冒充完成标定后的机械臂世界坐标。
- 角点对齐直接输出 `suction_box_corner` 和 `suction_cup_corner`。

## 界面

- 左侧控制栏：文件导入、指标状态、托盘、传送带姿态、传送带 Z、播放/暂停/单步/复位、速度。
- 中央视图：等轴投影显示传送带、当前箱子、吸盘、托盘和已放置箱子；动画阶段为等待、下降抓取、吸附抬升、旋转搬运、下降放置、释放。
- 右侧数据栏：当前箱子身份、顺序、抓取数据、角点对齐、箱子放置坐标、吸盘中心目标、旋转角度和验证状态。
- 底部动作表：列出当前托盘所有箱子的执行顺序和计算结果，点击行可跳转到该箱子。

## 错误处理

- 支持当前“根对象映射到托盘方案”的 JSON，也兼容字段文档中的 `pallets` 数组。
- 文件格式错误、无托盘、筛选后无结果、托盘无箱子时在界面中给出明确提示。
- 数值字段缺失时只对可安全推导的字段使用回退值；关键对象缺失则跳过并报告。

## 验证

- 单元测试覆盖两种 JSON 根结构、状态筛选、顺序回退、抓取 Z、吸盘中心和 0°/90° 旋转计算。
- Qt 冒烟测试使用离屏平台创建并关闭主窗口。
- 使用样例 JSON 完成解析和界面启动验证。
