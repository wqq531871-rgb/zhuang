# 传送带位置与旋转角点修正设计

## 修正目标

- 传送带从托盘 X 负方向改为托盘 +Y 外侧，并在 X 方向居中。
- 抓取角点和放置角点拆开表达。
- 放置阶段箱子角点与吸盘角点固定为绿色标记对应的 `x_max_y_max`。
- 需要旋转 90° 时，在抓取阶段选择旋转后会映射到 `x_max_y_max` 的对应角点。

## 角点规则

- 目标姿态等于传送带姿态：抓取双方使用 `x_max_y_max`。
- 0° 旋转到 90°：抓取双方使用 `x_max_y_min`。
- 90° 旋转到 0°：抓取双方使用 `x_min_y_max`。
- 放置双方始终使用 `x_max_y_max`。

吸盘放置中心以箱子绿色角点 `(position.x + raw_length, position.y + raw_width)` 为锚点重新计算。目标姿态为 0° 时中心为 `(x+raw_length-300, y+raw_width-400)`；目标姿态为 90° 时中心为 `(x+raw_length-400, y+raw_width-300)`。接触 Z 仍为 `position.z + raw_height`。

## 场景规则

传送带 X 范围在托盘宽度内居中，Y 最小值大于托盘 `pallet_width`。当前箱子在传送带中心生成，动画轨迹由该位置移动至托盘目标。

## 输出

导出 JSON 的 `pickup` 保存抓取角点，`placement` 新增放置箱子角点和放置吸盘角点；右侧详情同时显示两组角点。
