# 单箱姿态与绿色角点修正设计

## 目标

- 以用户截图绿色点为准，将箱子和吸盘的放置对齐角点定义为 `x_max_y_max`。
- 传送带箱姿态按单个箱子编辑，而不是对当前托盘全部箱子统一修改。

## 角点与吸盘中心

- 放置箱子角点与吸盘角点固定为 `x_max_y_max`。
- 无旋转时抓取角点为 `x_max_y_max`。
- 0°→90° 时，动画按正向 90° 旋转，抓取角点为 `x_max_y_min`。
- 90°→0° 时，动画按反向 90° 旋转，抓取角点为 `x_min_y_max`。
- 放置吸盘中心从箱子右上角 `(x + raw_length, y + raw_width)` 和吸盘右上角反推。

## 单箱姿态状态

- 姿态状态使用 `(plan.source_key, item.id)` 作为键，值为 0 或 90。
- 新加载的箱子默认 0°。
- 选择箱子时，姿态下拉框同步显示该箱当前值。
- 修改下拉框时，只更新当前选中箱子；保持当前箱子和播放步不变。
- 箱子列表显示每箱姿态，导出动作中的每条 `pickup.conveyor_orientation_deg` 保存各自值。

## 验证

- 数据测试覆盖绿色角点规则与吸盘中心。
- UI 测试覆盖修改第二个箱子不影响第一个箱子，以及切换箱子时下拉框同步。
- 完整测试后渲染抓取和放置画面进行视觉检查。
