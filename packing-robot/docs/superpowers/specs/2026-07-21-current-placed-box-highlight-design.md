# 当前放置箱橙色高亮设计

## 显示规则

- 当前箱在传送带、抓取、提升、搬运和下降过程中保持箱型原本颜色。
- `PLACE_DESCEND` 到达 100% 时视为已经放下，当前活动箱改为橙色。
- `RELEASE` 和 `RETRACT` 阶段继续保持橙色。
- 播放进入下一箱后，上一箱仍保持橙色并保持完全不透明。
- 下一箱在传送带、抓取、搬运和下降过程中，上一箱始终保持橙色。
- 只有下一箱实际下降到位后，上一箱才恢复箱型原本颜色，下一箱接替为橙色。
- 最后一箱完成后保持橙色，便于识别最后完成的动作。

## 实现方式

在三维场景模块增加纯函数，根据当前步骤、动画阶段和阶段进度计算“最新已放置箱”索引。每帧同时更新历史箱和活动箱颜色，避免步骤切换时过早清除橙色高亮。

## 验证

单元测试覆盖放置前、下降完成、释放和下一箱开始四种状态；完整测试后渲染相邻两个箱子的关键帧检查颜色切换。
