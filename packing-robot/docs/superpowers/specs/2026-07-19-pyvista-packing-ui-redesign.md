# PyVista 机器人装箱界面改造设计

## 目标

将当前 QPainter 等轴投影界面替换为与 `D:\research_code\zx-shunxu` 参考系统一致的 PySide6 + PyVista 交互式三维界面，并在托盘左侧加入传送带、待抓箱子和 600×800 mm 吸盘的完整抓取放置动画。

## 选择的方案

把参考项目的三栏窗口、PyVista 场景和底部播放控制架构移植到当前项目，但继续使用当前项目已经验证的 JSON 兼容解析、SUCCESS 筛选和机器人动作数据计算。当前项目保持独立运行，不在运行时引用兄弟目录。

## 界面结构

- 左侧：指标状态、托盘类型、托盘编号、订单号、传送带箱子姿态 0°/90°、箱子执行顺序、导入与导出。
- 中间：PyVista OpenGL 场景；支持鼠标旋转、缩放和平移。底部为首箱、上一箱、播放/暂停、下一箱、末箱、进度条、阶段和倍速。
- 右侧：当前托盘、箱子、抓取 Z、角点对齐、放置 X/Y/Z、吸盘目标中心、旋转角度和当前动画阶段。

## 三维场景

- 托盘位于局部坐标原点，显示木色托盘底板。
- 托盘全部目标箱体以低透明度显示；已经完成的箱体变为高透明度实体。
- 传送带位于托盘 X 负方向，带有底座、皮带面和辊筒视觉结构。
- 当前箱子每一步都在传送带抓取点重新生成。
- 吸盘为半透明青色 600×800×50 mm 长方体，不显示机械臂。
- 三维坐标轴和默认等轴相机沿用参考系统。

## 动画阶段

1. `READY`：箱子在传送带，吸盘位于安全高度。
2. `PICK_DESCEND`：吸盘下降到箱子顶面。
3. `PICK_ATTACH`：吸附保持。
4. `LIFT`：吸盘带箱子抬升到安全高度。
5. `TRANSFER`：吸盘与箱子平移到托盘目标点上方，同时完成 0°/90° 旋转。
6. `PLACE_DESCEND`：吸盘带箱子下降到 JSON 指定位置。
7. `RELEASE`：箱子固定到托盘，吸盘释放。
8. `RETRACT`：吸盘垂直抬回安全高度。

## 数据规则

- 动作顺序、抓取 Z、放置坐标、吸盘中心和角度继续来自 `packing_ui.data`。
- 传送带箱子姿态由左侧 0°/90° 下拉框控制。
- 当前样例的对象映射根结构和文档中的 `pallets[]` 根结构都继续支持。
- 真实机械臂坐标变换仍不在本次可视化范围内。

## 验证

- 单元测试覆盖八阶段播放控制和空间插值终点。
- UI 离屏测试关闭三维部件，验证三栏控件、默认 SUCCESS 和 0°。
- 使用真实窗口后端启动 PyVista 场景并生成截图，与参考布局对照检查。
