# 相机视觉接入与 PLC A/B 控制设计

## 目标

将传送带箱子从 UI 默认生成改为由相机视觉数据驱动，并为 PLC 生成两个核心控制量：

- `rotation_state = 1`：不旋转；
- `rotation_state = 2`：吸取后旋转 90°；
- `pickup_point = "A"`：使用 A 吸附点；
- `pickup_point = "B"`：使用 B 吸附点。

角点定义固定为：

- A：`x_min_y_min`；
- B：`x_max_y_min`。

A/B 按箱子当前姿态的 XY 包络定义。旋转动作统一采用负向 90°，使抓取 B 点在目标姿态下转化为放置 A 点。

## 数据流

1. 装箱 JSON 按 `seq` 给出箱子顺序、托盘放置位置和目标姿态。
2. 相机数据给出当前传送带箱子的 ID、X/Y/Z 和姿态（0°或90°）。
3. 系统把相机姿态与当前装箱目标姿态比较。
4. 姿态相同则生成 `rotation_state = 1`，否则生成 `rotation_state = 2`。
5. 不旋转时选择 A 点；旋转时选择 B 点。
6. UI 按相机数据在传送带上绘制箱子，并突出显示当前 A/B 吸附点。
7. PLC 指令输出当前箱子的抓取、旋转和放置数据。

## 相机输入模型

软件接收单箱 JSON 对象：

```json
{
  "box_id": "WCS-0004-ZX222-0007",
  "x": 420.0,
  "y": -1100.0,
  "z": 0.0,
  "orientation_deg": 0,
  "timestamp": "2026-07-23T10:30:00+08:00",
  "confidence": 0.98
}
```

第一阶段提供“导入相机 JSON”入口和可复用的 `receive_camera_data` 业务接口。后续接入 TCP、Modbus、Profinet 或厂商 SDK 时只替换传输适配器，不修改装箱计算和三维显示。

若相机数据未提供 X/Y/Z，系统使用当前传送带默认位置作为兼容回退；姿态是必需字段，且只能为 0 或 90。

## 动作与 PLC 输出模型

每条动作增加：

```json
{
  "camera": {
    "received": true,
    "box_id": "WCS-0004-ZX222-0007",
    "x": 420.0,
    "y": -1100.0,
    "z": 0.0,
    "orientation_deg": 0,
    "timestamp": "2026-07-23T10:30:00+08:00",
    "confidence": 0.98
  },
  "plc": {
    "rotation_state": 2,
    "pickup_point": "B",
    "pickup_point_code": 2
  }
}
```

字段规则：

| 字段 | 值 | 含义 |
| --- | --- | --- |
| `rotation_state` | 1 | 相机姿态与托盘目标姿态相同，不旋转 |
| `rotation_state` | 2 | 两个姿态相差 90°，旋转 90° |
| `pickup_point` | A | `x_min_y_min` |
| `pickup_point` | B | `x_max_y_min` |
| `pickup_point_code` | 1 | A 点的 PLC 数值 |
| `pickup_point_code` | 2 | B 点的 PLC 数值 |

PLC 指令文件按当前托盘动作顺序输出，并保留现有抓取 Z、放置 XYZ、吸盘中心和目标姿态字段。

## UI 设计

左侧增加“视觉与 PLC”区域：

- “导入相机 JSON”按钮；
- 相机数据状态：等待、已接收、错误；
- 当前视觉箱子 ID；
- 相机姿态；
- A/B 吸附点；
- 旋转状态。

右侧当前信息增加：

- 相机坐标；
- 相机置信度和时间；
- `rotation_state` 数值及中文含义；
- `pickup_point`、`pickup_point_code` 和几何角点。

箱子顺序列表增加简写，例如：

```text
1. BOX-001  相机0° → 目标90° / 转(2) / B
```

三维场景在箱子顶面显示 A、B 标记，并突出当前选中的吸附点。收到相机坐标后，READY 和抓取阶段使用相机位置；未收到数据时仍显示默认位置，但 UI 明确标注“等待相机数据”，用于离线演示和兼容旧文件。

## 错误处理

- 姿态不是 0 或 90：拒绝该条相机数据并显示错误；
- 箱子 ID 不在当前托盘动作中：拒绝绑定并显示错误；
- JSON 缺少有效对象：不覆盖上一条有效数据；
- 相机箱子 ID 与当前步骤不一致：UI 显示不匹配，PLC 指令标记为不可执行；
- 未收到相机数据：允许三维离线预览，但 PLC 指令中的 `ready` 为 `false`。

## 验证

- 单元测试覆盖 0→0、90→90、0→90、90→0；
- 测试 A/B 与 PLC 数值映射；
- 测试相机数据校验和按箱子 ID 绑定；
- 测试导出 PLC 指令字段；
- UI 冒烟测试检查视觉状态、A/B 和旋转状态显示；
- 三维测试检查相机坐标覆盖默认传送带位置。
